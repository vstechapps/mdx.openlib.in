MDX / DEVELOPER GUIDE

Markdown in.
Beautiful HTML out.

Add the MDX renderer to any browser page with one script. It parses and sanitizes Markdown, with optional themes and slide formatting built in.

01

Include the bundle

The bundle includes Marked, DOMPurify, and the MDX renderer.

<script src="https://mdx.openlib.in/js/markdown.min.js" defer></script>

After it loads, the API is available as window.MDXMarkdown. Since the script uses defer, run your setup after DOMContentLoaded, as shown below. No separate Marked or DOMPurify scripts are needed.

02

Render Markdown

Pass a Markdown string to renderPreview, then insert the sanitized HTML into your page.

document.addEventListener("DOMContentLoaded", () => {
  const markdown = "# Hello\n\nRendered with **MDX**.";
  const html = MDXMarkdown.renderPreview(markdown);
  document.querySelector("#preview").innerHTML = html;
});

Add a target element wherever the rendered content should appear:

<div id="preview"></div>
03

Apply a theme

Load the theme stylesheet and pass the theme name as the third argument.

<link rel="stylesheet"
  href="https://mdx.openlib.in/css/markdown-preview-themes.css">

const html = MDXMarkdown.renderPreview(markdown, "pdf", "warm");
document.querySelector("#preview").innerHTML = html;
classic executive warm dark

Use this themed call in place of the render call above. The stylesheet applies typography and colors; your site controls the surrounding layout, width, and spacing.

04

Render slides

Use "ppt" mode to split Markdown into slide sections.

const slides = MDXMarkdown.renderPreview(markdown, "ppt", "executive");
document.querySelector("#deck").innerHTML = slides;

Separate slides with a line containing ---. The result is a sequence of .slide sections; add your own navigation and presentation controls if needed.

05

API reference

Small surface, easy to drop into an existing page.

MethodWhat it does
renderPreview(markdown, mode, theme)Returns sanitized HTML. Mode is "pdf" by default; pass "ppt" for slides. Theme is optional.
splitSlides(markdown)Returns slide text sections, split on horizontal rules or headings.
registerFolderFiles(fileList)Registers local folder images so relative Markdown image paths can resolve.
imageCount()Returns the number of registered image path entries.
